# Studio Re Fontes — site institucional

Projeto independente do Studio Re Fontes, Dublin 8. React + Vite + TypeScript.

## Pastas

- `src/App.tsx`: layout, menus, textos e links de agendamento
- `src/index.css`: estilos e responsividade
- `src/main.tsx`: ponto de entrada do React
- `index.html`: título, SEO e inicialização
- `vite.config.ts`: build Vite
- `vercel.json`: fallback para rotas do site

## Publicar

1. Envie **o conteúdo da pasta extraída** para a raiz do repositório `siterefontes/Siterefontes`.
2. Na Vercel, importe o repositório na equipe correta.
3. Selecione Framework Preset **Vite**, Root Directory **./**, Build Command **npm run build**, Output Directory **dist**.
4. Instalação: **npm install**.

## Executar localmente

```bash
npm install
npm run dev
npm run build
```

## Atenção antes de publicar

O botão de reserva aponta para o Treatwell oficial. As avaliações exibidas são atribuídas ao Treatwell e não ao Google. Confirme os horários, a oferta de serviços e a autorização de uso da fotografia carregada do CDN do Treatwell antes do lançamento.
